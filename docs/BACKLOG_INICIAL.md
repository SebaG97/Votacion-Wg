# Backlog Inicial

## Fase 1 - Base Del Proyecto

- Crear estructura backend/frontend.
- Definir variables de entorno.
- Documentar reglas de negocio.
- Preparar modelo de datos inicial.
- Crear misiones ejecutables del proyecto.

Ver detalle operativo en `docs/MISIONES.md`.

## Fase 2 - Analisis Del Excel

- Recibir archivo Excel base.
- Identificar columnas y hojas.
- Detectar duplicados de celular.
- Detectar matrimonios, grupos, jefes y consagracion.
- Generar informe de calidad de datos.

## Fase 3 - Backend

- Configurar FastAPI.
- Configurar base de datos y Alembic.
- Implementar importador de padron.
- Implementar normalizacion a unidades electorales.
- Implementar consulta por celular.
- Implementar emision de voto.
- Implementar cierre y revelacion de resultados.
- Agregar pruebas de reglas criticas.

## Fase 4 - Frontend

- Configurar React/Vite.
- Crear flujo de consulta por celular.
- Crear pantalla de voto.
- Crear panel administrativo.
- Crear pantalla de resultados cerrados.
- Manejar estados de error e incidencias.

## Fase 5 - Operacion

- Carga inicial del padron.
- Validacion con usuarios responsables.
- Prueba general.
- Backup antes de apertura.
- Apertura, monitoreo, cierre y revelacion.
